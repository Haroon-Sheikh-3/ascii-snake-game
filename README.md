# ASCII Snake Game 🐍

A classic Snake game built with Python and Tkinter, featuring an ASCII-inspired visual style.

## Features
- Keyboard-controlled snake movement
- Food collection and score tracking
- Collision detection and game-over handling
- Game window built with Tkinter

## Technologies
- Python
- Tkinter

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Run:

```bash
python main.py
```

Enjoy the game!
